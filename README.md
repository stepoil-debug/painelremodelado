# STEP Painel Operacional Remodelado

Novo painel operacional da STEP, criado de forma isolada para organizar demandas por setor, integrar em modo somente leitura os dados do Apontamento HH e preparar o fluxo de handoff/notificações entre áreas.

> Segurança: este repositório não altera o aplicativo de Apontamento HH nem executa migrações automaticamente no banco operacional existente.

O desenvolvimento da V1 ocorre em branch isolada antes de qualquer integração com o STEP One.
